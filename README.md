JS-Tools Extension (JS-Tools-Ext)

JS-Tools-Ext — це потужне та універсальне розширення для браузера, призначене для інтерактивної взаємодії, автоматизації, аналізу та покращення досвіду користувача під час роботи з різними типами веб-контенту (відео, тести/вікторини, презентації, PDF-документи, потоки даних тощо).

🏗 Огляд та Архітектура

Розширення побудоване за сучасною архітектурою Manifest V3 і розбите на чіткі модулі за принципом поділу відповідальності (Separation of Concerns):

┌─────────────────────────────────────────────────────────┐
│                      Popup (UI)                         │
│  (popup.html / popup.js / dropdown.js / neon-bg.js)    │
└────────────────────────────┬────────────────────────────┘
                             │ Message Passing
┌────────────────────────────▼────────────────────────────┐
│                  Background Worker                      │
│                   (background.js)                       │
└────────────────────────────┬────────────────────────────┘
                             │ Content Scripts
┌────────────────────────────▼────────────────────────────┐
│                    Content Script                       │
│                     (content.js)                        │
└────────────────────────────┬────────────────────────────┘
                             │ Engine Modules
┌────────────────────────────▼────────────────────────────┐
│                   Engine Ecosystem                      │
│   check.js │ common.js │ flow.js │ pdf.js │ quiz.js... │
└─────────────────────────────────────────────────────────┘

🔍 Детальний Аналіз Модулів та Файлів

Основа Розширення (Core)

manifest.json

Призначення: Конфігураційний файл Chrome Extension (Manifest V3).

Деталі: Визначає дозволи (permissions, host_permissions), оголошує background.service_worker, зареєстровані content_scripts, іконки та сторінку action.default_popup.

background.js

Призначення: Сервіс-воркер розширення.

Деталі: Обробляє події встановлення/оновлення розширення, керує фоновими завданнями, міжвкладковою комунікацією (Message Bus) та централізованим збереженням стану (chrome.storage).

content.js

Призначення: Контентний скрипт, що виконується в контексті відкритих веб-сторінок.

Деталі: Здійснює безпосередній доступ до DOM сторінки, взаємодіє з модулями engine/, зчитує необхідні дані, додає власні елементи керування та передає повідомлення до background.js / popup.js.

config.js

Призначення: Конфігурація та глобальні константи.

Деталі: Зберігає ключі API, конфігурації за замовчуванням, таймаути, URL-селектори та селектори елементів сторінки для різних сайтів.

Двигун та Функціональні Модулі (engine/)

Папка engine/ містить ключові бізнес-модулі для роботи з різними типами вмісту:

engine/common.js

Призначення: Утиліти загального призначення.

Деталі: Функції для форматування даних, роботи з DOM (знаходження елементів, затримки sleep(), генерація унікальних ID), парсинг рядків та обробка помилок.

engine/check.js

Призначення: Модуль валідації та перевірок.

Деталі: Аналізує поточний стан сторінки, перевіряє доступність елементів інтерфейсу, перевіряє правильність вхідних даних та коректність виконання операцій.

engine/flow.js

Призначення: Менеджер потоків виконання (Workflow Engine).

Деталі: Оркеструє послідовність кроків, керує чергою виконання автоматичних дій та очікуванням потрібних подій на сторінці.

engine/quiz.js

Призначення: Модуль взаємодії з тестами та вікторинами.

Деталі: Парсить питання, варіанти відповідей, автоматизує або підказує вибір правильних відповідей у навчальних системах.

engine/slides.js

Призначення: Обробник презентацій та слайдів.

Деталі: Дозволяє переключати, аналізувати, завантажувати або експортувати вміст онлайн-презентацій.

engine/video.js

Призначення: Модуль роботи з відеоконтентом.

Деталі: Керує HTML5 <video> елементами (зміна швидкості відтворення, пропуск паузи, автоматичне переглядання, захоплення кадрів чи субтитрів).

engine/pdf.js

Призначення: Модуль обробки PDF-документів.

Деталі: Дозволяє витягувати текст, завантажувати або переглядати PDF-файли, вбудовані у веб-сторінки.

Інтерфейс Користувача (UI & Scripts)

popup.html

Призначення: HTML-структура спливаючого вікна (Popup).

Деталі: Містить елементи керування (кнопки, перемикачі, дропдауни) для запуску різних інструментів та налаштування розширення.

popup.js

Призначення: Логіка управління UI.

Деталі: Зчитує вибір користувача, ініціалізує налаштування, надсилає команди у content.js та оновлює статус роботи інструментів.

js/dropdown.js

Призначення: Кастомний каскадний або випадаючий список.

Деталі: забезпечує стильний та анімований UI для вибору опцій та параметрів у popup-вікні.

js/neon-bg.js

Призначення: Візуальний ефект інтерфейсу.

Деталі: Генерує інтерактивний/динамічний неоновий фон у вікні розширення для покращення UX та сучасного дизайну.

Ресурси та Стилі (Assets & CSS)

css/style.css

Призначення: Таблиця стилів розширення.

Деталі: Описує кастомний дизайн для popup.html, анімації неонового фону, випадаючих списків та елементів, що впроваджуються на веб-сторінки.

ico/

Призначення: Набір графічних іконок.

Деталі: Включає векторну версію ico.svg та растрові розширення PNG (16x16, 32x32, 48x48, 128x128) для відображення в панелі Chrome, менеджері розширень та меню.
