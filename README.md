# JS-Tools Extension (JS-Tools-Ext)

**JS-Tools-Ext** — потужне та універсальне розширення для браузера, призначене для автоматизації, аналізу та покращення взаємодії з вебконтентом.

Розширення містить інструменти для роботи з відео, тестами та вікторинами, презентаціями, PDF-документами й іншими типами вебконтенту.

## 🏗 Огляд та архітектура

JS-Tools-Ext побудовано на основі сучасного стандарту **Manifest V3** із використанням модульної архітектури та принципу розподілу відповідальності (*Separation of Concerns*).

Кожен компонент має власне призначення, що спрощує підтримку, налагодження та подальше розширення функціональності.

### Схема архітектури

```text
┌─────────────────────────────────────────────────────┐
│                  Popup (інтерфейс)                   │
│       popup.html · popup.js · скрипти інтерфейсу     │
└──────────────────────────┬──────────────────────────┘
                           │
                  Обмін повідомленнями
                           │
┌──────────────────────────▼──────────────────────────┐
│                   Фоновий процес                    │
│                    background.js                    │
└──────────────────────────┬──────────────────────────┘
                           │
                  Обмін повідомленнями
                           │
┌──────────────────────────▼──────────────────────────┐
│                Скрипт вебсторінки                    │
│                     content.js                      │
└──────────────────────────┬──────────────────────────┘
                           │
                  Функціональні модулі
                           │
┌──────────────────────────▼──────────────────────────┐
│                  Система модулів                    │
│                                                     │
│   common.js · check.js · flow.js · quiz.js          │
│             slides.js · video.js · pdf.js            │
└─────────────────────────────────────────────────────┘
```

### Основні компоненти

| Компонент | Призначення |
|:--|:--|
| **Popup UI** | Взаємодія з користувачем і налаштування інструментів |
| **Background Worker** | Обробка фонових подій і координація роботи розширення |
| **Content Script** | Взаємодія з вебсторінками та їхнім DOM |
| **Engine Modules** | Обробка контенту й автоматизація операцій |
| **Assets & CSS** | Іконки, стилі, анімації та візуальні ефекти |

## ⚙️ Основні файли розширення

### `manifest.json`

**Призначення:** конфігураційний файл розширення для браузера на основі Manifest V3.

**Основні функції:**
- Визначення дозволів і доступу до вебсайтів.
- Налаштування фонового сервіс-воркера.
- Реєстрація скриптів, що виконуються на вебсторінках.
- Визначення іконок і сторінки спливаючого вікна.

### `background.js`

**Призначення:** фоновий сервіс-воркер, який координує роботу розширення.

**Основні функції:**
- Обробка подій встановлення та оновлення.
- Виконання фонових завдань.
- Організація обміну повідомленнями між компонентами.
- Робота зі спільним станом і сховищем через API браузера Chrome.

### `content.js`

**Призначення:** скрипт, який виконується в контексті підтримуваних вебсторінок.

**Основні функції:**
- Взаємодія з DOM вебсторінки.
- Підключення функціональних модулів.
- Отримання необхідних даних зі сторінки.
- Додавання власних елементів керування.
- Обмін повідомленнями з іншими компонентами розширення.

### `config.js`

**Призначення:** централізоване зберігання конфігурації та констант.

**Основні функції:**
- Зберігання параметрів за замовчуванням.
- Налаштування тайм-аутів і селекторів.
- Визначення параметрів для підтримуваних вебсайтів та їхніх елементів.

## 🧩 Функціональні модулі

Каталог `engine/` містить спеціалізовані модулі для роботи з різними типами вебконтенту.

### `engine/common.js`

**Призначення:** загальні допоміжні функції.

Містить інструменти для:
- Пошуку та обробки DOM-елементів.
- Виконання асинхронних операцій і затримок.
- Форматування даних і обробки рядків.
- Генерації унікальних ідентифікаторів.
- Обробки помилок.

### `engine/check.js`

**Призначення:** перевірка стану сторінки та діагностика.

Відповідає за:
- Перевірку доступності необхідних елементів інтерфейсу.
- Валідацію вхідних даних.
- Перевірку умов виконання операцій.
- Аналіз результатів виконання.

### `engine/flow.js`

**Призначення:** керування послідовністю операцій (*Workflow Engine*).

Організовує виконання послідовних дій, керує чергою автоматизованих операцій і очікує на необхідні події вебсторінки.

### `engine/quiz.js`

**Призначення:** взаємодія з тестами та вікторинами.

Забезпечує роботу з інтерфейсами тестування, зокрема:
- Отримання запитань.
- Аналіз варіантів відповідей.
- Допомогу у виборі відповідей.
- Автоматизацію підтримуваних операцій із тестами.

### `engine/slides.js`

**Призначення:** робота з презентаціями та слайдами.

Містить інструменти для навігації презентаціями, взаємодії зі слайдами та обробки їхнього вмісту, якщо це підтримується відповідним вебсайтом.

### `engine/video.js`

**Призначення:** взаємодія з відеоконтентом.

Працює з елементами HTML5 `<video>` та забезпечує доступ до підтримуваних операцій:
- Керування відтворенням.
- Зміна швидкості відтворення.
- Отримання доступної інформації про медіаконтент.
- Робота з іншими підтримуваними функціями відеоплеєра.

### `engine/pdf.js`

**Призначення:** обробка PDF-документів.

Містить інструменти для взаємодії з PDF-файлами, вбудованими у вебсторінки, зокрема для отримання тексту та доступу до вмісту документів, якщо це підтримується.

## 🖥️ Інтерфейс користувача та скрипти

### `popup.html`

**Призначення:** HTML-структура спливаючого вікна розширення.

Містить елементи керування, необхідні для запуску інструментів і налаштування параметрів.

### `popup.js`

**Призначення:** логіка роботи інтерфейсу.

**Основні функції:**
- Обробка вибору користувача.
- Ініціалізація параметрів інтерфейсу.
- Надсилання команд іншим компонентам розширення.
- Оновлення стану інструментів та елементів інтерфейсу.

### `js/dropdown.js`

**Призначення:** власні компоненти випадаючих списків.

Забезпечує взаємодію з елементами вибору та їхню візуальну поведінку у спливаючому вікні.

### `js/neon-bg.js`

**Призначення:** анімований неоновий фон.

Створює динамічні візуальні ефекти за допомогою Canvas API, доповнюючи оформлення інтерфейсу розширення.

## 🎨 Ресурси та стилі

### `css/style.css`

**Призначення:** основна таблиця стилів розширення.

Визначає оформлення:
- Спливаючого вікна та його елементів керування.
- Випадаючих списків.
- Анімацій і візуальних ефектів.
- Елементів, які додаються до вебсторінок.

### `ico/`

**Призначення:** графічні ресурси та іконки розширення.

Містить векторні й растрові версії іконок для панелі браузера, менеджера розширень та інших елементів інтерфейсу.

| Файл | Опис |
|:--|:--|
| `ico.svg` | Векторна іконка |
| `ico16.png` | Іконка розміром 16 × 16 пікселів |
| `ico32.png` | Іконка розміром 32 × 32 пікселі |
| `ico48.png` | Іконка розміром 48 × 48 пікселів |
| `ico128.png` | Іконка розміром 128 × 128 пікселів |
